# v1.3.0 媒体交付候选验证

2026-10-26，开发候选，本地独立验收通过；尚未创建正式 v1.3.0 Release。GitHub 六组跨平台 CI 状态另见当前 PR 的检查项。已发布 v1.2.0 的标签、附件和快捷安装地址保持原样。

## 本轮实际执行

Windows，Python 3.11.9 与 3.12.14 分别运行原 52 项打包检查（50 通过、2 项普通文件 symlink 因权限跳过）、原 31 项接手/安装检查、28 项大文件扩展检查，均符合预期。大文件入口的两项兼容性 wrapper 不重复计数。详细命令及退出码见[兼容性记录](validation-v1.3-compatibility.json)。原打包器、接手检查器、安装器及旧测试源码相对本轮基线未修改。

两个 Python 版本分别运行新增 33 项媒体检查：32 通过、1 项普通文件 symlink 因权限跳过。Windows junction 别名回归实际执行通过。覆盖声明校验、摘要与资源上限、缺工具、未知时长、技术期望，以及真实小子进程的超时和输出限制；受控 probe JSON 不冒充真实媒体解析。见[媒体测试记录](validation-v1.3-media-tests.json)。

接收方另行检查冻结实现，11 个独立用例全部符合预期：真实 MP4 + SRT、PCM WAV、MP3、缺必需音轨、允许静音、错误尺寸、损坏文件、缺工具、零时长、不可表示数值，以及包内伪装 ffprobe 的自动发现拒绝。最后一项使用模拟进程调用器，未执行伪装程序。见[独立集成记录](media-v1.3-integration.json)。

真实样本由本地合成，未使用用户录音或外部下载。环境为本机已有 FFmpeg/ffprobe 8.1.2-essentials_build-www.gyan.dev：MP4 为 3 秒、320×180 H.264 + 48kHz 单声道 AAC；WAV 为 3 秒、16kHz 单声道 PCM；MP3 由合成 WAV 编码，容器时长可能含编码填充。源文件字节数分别为 144356、96044、4293。

## 从 ZIP 独立接手

实际完成打包、摘要校验、接手检查，在新目录解压后使用包内工具生成新的接收方媒体报告。发送端与接收端的媒体摘要、字节数、时长及流信息一致。声明中的 independent_acceptance 保持 UNKNOWN；外部接收记录仅接受本次合成样本的技术交付。见[接收记录](media-v1.3-demo-results.json)。

## 安装与验收过程

skill 格式检查通过。release-manifest 逐个核对 11 个 skill 文件，隔离目录预览和实际安装通过，安装内容的长度与 SHA-256 与源清单一致。现用全局 skill 未替换；未声称各 IDE 的自动发现均已实测。

实现经过三次独立 attempt：首轮反馈零时长不能算通过；第二轮遭遇模型服务传输失败，部分结果保留并标为未完成；第三轮完成返修和包内工具自动发现防护。超大数值的固定错误码也经过独立回归。最终接收冻结源码 SHA-256 为 fb41da7e9bb095c9629779c7c6b45d286203fb28bc1a0e76a946e4c2eb6d28d9。工作者自测与接收方决定分别记录，未用自测替代独立验收。

## 尚未验证的边界

- 画质、听感、字幕/文字稿同步和可编辑工程导入均为人工检查，本轮 not_run。
- 技术参数读取不等于全片解码、任意播放器兼容或恶意媒体隔离。
- GB 媒体的检查性能、真实用户剪辑/录音工作流、更多容器和旧版 ffprobe 尚未验证。视频演示使用 large 只是配置路径验证，不是 GB 压力证明。
- 本轮未重跑 GB 边界压力；[v1.2 压力记录](VALIDATION-v1.2.md)是历史证据，不能外推为媒体模块实测。
- 不制作、转码、自动转写、下载或上传媒体；缺 ffprobe 明确记为 not_run，不自动安装依赖。
