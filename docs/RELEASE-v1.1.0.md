# package-delivery v1.1.0

首个公开版本，MIT许可。仓库所有者已查看快捷安装和公开范围，并批准发布源码、v1.1.0标签、ZIP及SHA256SUMS。

## 本次解决的问题

合作者交回ZIP后，文件齐全还不足以确认任务交齐。本版将每条验收要求关联到具体产物和验证记录，并把验证绑定到交付文件的实际摘要。返修说明上一包摘要、解决的反馈和本轮验证，便于接收方复验。

保留已验证的v1打包助手；新检查器要求可追溯扩展，旧包仍可做基础完整性验证。新增本地安装器，提供dry-run、不覆盖默认值、显式升级与备份。提供npx固定版本安装指令作为可选路径。

## 环境

- 核心工具与安装器：Python3.11+标准库，无pip依赖或API Key。
- GitHub clone方式另需Git和网络；npx方式另需Node.js≥22.20、npm/npx、Git和网络。
- 客户端可直接读取SKILL.md；Codex/Claude目录安装与客户端原生发现是不同验证项。

## 验证与短板

发布前实际结果见[VALIDATION.md](VALIDATION.md)，发布后远端CI和固定标签安装结果见[POST-RELEASE.md](POST-RELEASE.md)。客户端原生发现仍未验证。

脚本检查元数据一致性与文件完整性，不评判产物质量、日志真实性或作者身份；不做内容级秘密扫描。512文件、64MiB单文件和128MiB总解压上限仍保留。还没有足够日常任务样本证明生产力提升。
